## Destaques

- 🧾 **OCR de notas fiscais em produção**: leitura automática de NFC-e e PDFs rodando no próprio servidor, sem API externa. A migração de PaddleOCR para RapidOCR (ONNX Runtime) reduziu a imagem do contêiner pela metade.
- 🔒 **Consistência de dados no banco**: atomicidade de estoque garantida com funções plpgsql e `SELECT ... FOR UPDATE`, impedindo saldo negativo em operações simultâneas.
- 🔗 **Integrações**: APIs REST, WebSocket e integrações com o setor financeiro.
- 🤖 **IA aplicada**: assistente de IA para agilizar o atendimento de chamados e desenvolvimento assistido por IA.
- 🏗️ **Arquitetura e qualidade**: ADRs, arquitetura hexagonal, CI/CD com GitHub Actions e testes unitários, de integração e ponta a ponta.
